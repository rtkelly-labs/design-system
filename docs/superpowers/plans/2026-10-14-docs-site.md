# Docs Site: Figures, MDX and Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the design system a docs site for its ideas. Five new MDX figures go in the package, an MDX pipeline goes in `apps/site`, and short Foundations and Guides posts are built around those figures.

**Architecture:** The figures live in `packages/design-system/src/components/docs/figures/` beside `BeforeAfter`, and are registered in the shared `mdxComponents` map so the blog gets them too. The site compiles `.mdx` pages with `@next/mdx` under Turbopack. Post metadata stays in the one registry (`src/content/`). Each post's sections are extracted from its headings at build time with the package's own `slugify`. Colour values on the pages come from `LEVELS` and `PALETTE_HUES`, never from literals.

**Tech Stack:** React 19, Next 16.3.6 (App Router, `output: 'export'`, Turbopack), `@next/mdx` with `remark-gfm` as a string plugin, Tailwind v4, Vitest with Testing Library, Storybook 10 with Playwright visual snapshots.

**Spec:** issues #374 (epic), #375 (figures), #376 (MDX and Colour post), #377 (remaining posts).

## Global Constraints

- **Three PRs**, in order: `375-docs-figures`, then `376-site-mdx`, then `377-site-posts`. Each is its own worktree under `design-system/temp/`. Never run a mutating git command in the repo root.
- **Colour is addressed by role.**
  - Components use semantic utilities only (`text-content-*`, `bg-surface-*`, `border-edge-*`, `text-intent-*`).
  - No hex literal may appear in `src/components/**` or `src/stories/**` (lint rule `design-system/no-colour-literals`, at error). That includes test files under `src/components`.
  - A colour drawn as data reaches the DOM only through `Swatch`, which already owns the one `style={{ backgroundColor }}`. New figures add **zero** `style={{…}}` literals (contract budget `inlineStyle: 91`).
- **Every new figure file satisfies all six component-contract clauses:**
  - a co-located `X.test.tsx`
  - `React.forwardRef(function X(…))`, which also serves as the displayName
  - `cn` imported from `../../../lib/recipe`
  - `{...rest}` spread on the root
  - no new inline style
  - a JSDoc directly above `export const X`, and a one-line JSDoc on every prop
- **Stories:**
  - Titles are `Docs/Figures/<Name>`, with tags `['autodocs', 'stable']`.
  - Each story file has three captioned stories, including `SketchTheme` with `globals: { level: 'sketch' }`, and sets `parameters.docs.description.component`.
  - Story fixtures read colours from `LEVELS`, never literals.
- **Visual rows:** each figure gets two rows in `tests/visual.spec.ts` (`--default` and `--sketch-theme`). Baselines come from `/update-snapshots all` on the PR, never from a local run.
- **Glyphs:** no new non-ASCII glyphs beyond `→ · —`, so that `check:fonts` stays green.
- **Pre-1.0:** bump `packages/design-system/package.json` minor, and add `^<new>` to `design-system-report`'s peer range in the same PR.
- **Prose budget:** about 250 words per post. Figures carry the argument.
- **Document only what `main` has.**
  - Type and ink weight, and anything showing APCA, waits until #373 is on `main`.
  - Reports cover HTML only. PDF waits for the #357–#359 stack.

```tsx
import * as React from 'react';
import { cn } from '../../../lib/recipe';
import type { ThemeLevel } from '../../../theme/levels';
import { Swatch } from '../../Swatch';

export type VerdictTone = 'neutral' | 'success' | 'warning' | 'info';

export interface SwatchColumn {
  /** Column heading, usually a hue or a role. */
  name: string;
  /** Short verdict under the column, e.g. `kept`, `lifted`, `new`. */
  verdict?: string;
  /** How the verdict reads. Defaults to `neutral`. */
  tone?: VerdictTone;
}

export interface SwatchRow {
  /** Row label, e.g. `Today` or `Now`. */
  label: string;
  /** One CSS colour per column, or `null` where no value exists. */
  values: readonly (string | null)[];
}

export interface SwatchCompareProps extends React.HTMLAttributes<HTMLDivElement> {
  /** Accessible name for the comparison table. */
  label?: string;
  /** Paint the swatches on this Level's ground. Omit to use the page's. */
  level?: ThemeLevel;
  /** The columns, left to right. */
  columns: readonly SwatchColumn[];
  /** One row per state being compared, top to bottom. */
  rows: readonly SwatchRow[];
  /** Additional classes for the outer frame. */
  className?: string;
}

const VERDICT: Record<VerdictTone, string> = {
  neutral: 'border-edge-default text-content-secondary',
  success: 'border-intent-success text-intent-success',
  warning: 'border-intent-warning text-intent-warning',
  info: 'border-intent-info text-intent-info',
};

/** Rows of colour across named columns, so a reader compares a palette before and after a change. */
export const SwatchCompare = React.forwardRef<HTMLDivElement, SwatchCompareProps>(function SwatchCompare(
  { label = 'Colour comparison', level, columns, rows, className, ...rest },
  ref,
) {
  return (
    <div ref={ref} {...rest} data-theme={level} className={cn('min-w-0 overflow-x-auto bg-surface-sunken p-3', className)}>
      <table aria-label={label} className="w-full border-collapse font-mono text-xs">
        <thead>
          <tr>
            <th scope="col" className="sr-only">State</th>
            {columns.map((c) => (
              <th key={c.name} scope="col" className="px-1 pb-2 text-center font-bold uppercase tracking-[0.08em] text-content-muted">
                {c.name}
              </th>
            ))}
          </tr>
        </thead>
        <tbody>
          {rows.map((row) => (
            <tr key={row.label}>
              <th scope="row" className="pr-3 text-left font-bold uppercase tracking-[0.08em] text-content-muted">{row.label}</th>
              {columns.map((c, i) => {
                const value = row.values[i] ?? null;
                return (
                  <td key={c.name} className="px-1 py-1 align-top">
                    {value === null ? (
                      <span
                        aria-label={`${row.label}: no ${c.name}`}
                        className="block h-10 w-full border-2 border-dashed border-edge-subtle"
                      />
                    ) : (
                      <Swatch value={value} name={value} size="md" className="flex-col items-start gap-1 [&>[data-slot=swatch-well]]:w-full" />
                    )}
                  </td>
                );
              })}
            </tr>
          ))}
          {columns.some((c) => c.verdict) && (
            <tr>
              <td />
              {columns.map((c) => (
                <td key={c.name} className="px-1 pt-2 text-center">
                  {c.verdict && (
                    <span className={cn('inline-block border-2 px-1 py-0.5 font-bold uppercase', VERDICT[c.tone ?? 'neutral'])}>{c.verdict}</span>
                  )}
                </td>
              ))}
            </tr>
          )}
        </tbody>
      </table>
    </div>
  );
});
```

The `Swatch` well is `w-10` by default. The child selector stretches it to the cell. If `Swatch` doesn't put `data-slot="swatch-well"` on the well, read `src/components/Swatch.tsx` and use whatever slot it does carry. Do not add a style literal.

```tsx
import * as React from 'react';
import { cn } from '../../../lib/recipe';

export type MetricTone = 'neutral' | 'success' | 'warning' | 'danger';

export interface Metric {
  /** The figure itself, already formatted, e.g. `5.5:1` or `+8.4%`. */
  value: string;
  /** What the figure counts, in a few words. */
  label: string;
  /** Colours the value by meaning. Defaults to `neutral`. */
  tone?: MetricTone;
}

export interface MetricStripProps extends React.HTMLAttributes<HTMLDListElement> {
  /** Accessible name for the strip. */
  label?: string;
  /** Two to five metrics, left to right. */
  items: readonly Metric[];
  /** Additional classes for the strip. */
  className?: string;
}

const TONE: Record<MetricTone, string> = {
  neutral: 'text-content-primary',
  success: 'text-intent-success',
  warning: 'text-intent-warning',
  danger: 'text-intent-danger',
};

/** A row of headline figures, each with a short label, read before the detail. */
export const MetricStrip = React.forwardRef<HTMLDListElement, MetricStripProps>(function MetricStrip(
  { label = 'Metrics', items, className, ...rest },
  ref,
) {
  return (
    <dl
      ref={ref}
      role="group"
      aria-label={label}
      {...rest}
      className={cn('m-0 grid grid-cols-2 border-2 border-edge-strong sm:grid-flow-col sm:auto-cols-fr sm:grid-cols-none', className)}
    >
      {items.map((m) => (
        <div key={m.label} className="flex min-w-0 flex-col-reverse gap-1 border-b border-r border-edge-subtle p-3 last:border-r-0">
          <dt className="font-mono text-[0.65rem] font-bold uppercase tracking-[0.1em] text-content-muted">{m.label}</dt>
          <dd className={cn('m-0 font-display text-xl font-extrabold tabular-nums', TONE[m.tone ?? 'neutral'])}>{m.value}</dd>
        </div>
      ))}
    </dl>
  );
});
```

`dt` follows `dd` in reading order because of `flex-col-reverse`, so screen readers announce the label first, which is correct for a `dl`. Check that `font-display` is a utility the package emits (`--font-display` in `theme.css`). If it isn't, use `font-[family-name:var(--ds-font-display)]`.

```tsx
import * as React from 'react';
import { cn } from '../../../lib/recipe';
import { Swatch } from '../../Swatch';

export interface TokenRow {
  /** The token's path, e.g. `text.muted`. */
  token: string;
  /** The value before the change. `null` reads as "did not exist". Omit when nothing changed. */
  before?: string | null;
  /** The value now. */
  after: string;
  /** One entry per `measures` heading, already formatted. */
  values?: readonly string[];
  /** Why this value, in a sentence. */
  note?: string;
}

export interface TokenTableProps extends React.HTMLAttributes<HTMLDivElement> {
  /** Accessible name for the table. */
  label?: string;
  /** Headings for the measured columns, e.g. `WCAG`, `APCA Lc`. */
  measures?: readonly string[];
  /** One row per token. */
  rows: readonly TokenRow[];
  /** Additional classes for the scroll container. */
  className?: string;
}

const CELL = 'border-b border-edge-subtle px-3 py-2 align-top';
const HEAD = 'border-b-2 border-edge-strong px-3 pb-2 text-left font-mono text-[0.65rem] font-bold uppercase tracking-[0.1em] text-content-muted';

function Chip({ value }: { value: string | null | undefined }) {
  if (value === undefined) return null;
  if (value === null) return <span className="font-mono text-xs text-content-muted">none</span>;
  return <Swatch value={value} name={value} size="sm" />;
}

/** Tokens with their values and measurements side by side, so a change is read as numbers, not taste. */
export const TokenTable = React.forwardRef<HTMLDivElement, TokenTableProps>(function TokenTable(
  { label = 'Tokens', measures = [], rows, className, ...rest },
  ref,
) {
  const hasBefore = rows.some((r) => r.before !== undefined);
  const hasNote = rows.some((r) => r.note);
  return (
    <div ref={ref} {...rest} className={cn('min-w-0 overflow-x-auto border-2 border-edge-strong', className)}>
      <table aria-label={label} className="w-full min-w-[34rem] border-collapse text-sm">
        <thead>
          <tr>
            <th scope="col" className={HEAD}>Token</th>
            {hasBefore && <th scope="col" className={HEAD}>Before</th>}
            <th scope="col" className={HEAD}>{hasBefore ? 'After' : 'Value'}</th>
            {measures.map((m) => <th key={m} scope="col" className={HEAD}>{m}</th>)}
            {hasNote && <th scope="col" className={HEAD}>Note</th>}
          </tr>
        </thead>
        <tbody>
          {rows.map((r) => (
            <tr key={r.token}>
              <th scope="row" className={cn(CELL, 'text-left font-mono text-xs font-bold text-content-primary')}>{r.token}</th>
              {hasBefore && <td className={CELL}><Chip value={r.before} /></td>}
              <td className={CELL}><Chip value={r.after} /></td>
              {measures.map((m, i) => <td key={m} className={cn(CELL, 'font-mono text-xs tabular-nums text-content-secondary')}>{r.values?.[i] ?? '—'}</td>)}
              {hasNote && <td className={cn(CELL, 'text-content-secondary')}>{r.note}</td>}
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
});
```

Fix the test's header expectation to match. With one measure and a note, and no before column, the headers are Token, Value, WCAG and Note: four.

```tsx
import * as React from 'react';
import { cn } from '../../../lib/recipe';
import { childItems, defineAsciiItem } from './FigureFrame';

export interface DecisionOption {
  /** The option, as a short heading. */
  title: string;
  /** What it costs, in a line. */
  cost?: string;
  /** Marks the recommended option. */
  picked?: boolean;
  /** One or two sentences on what the option does. */
  children?: React.ReactNode;
}

/** MDX-only option, for example `<Option title="5.5:1" picked cost="…">…</Option>`. */
export const Option = defineAsciiItem<DecisionOption>('Option');

export interface DecisionProps extends React.HTMLAttributes<HTMLDivElement> {
  /** The question being decided. Also the accessible name. */
  question: string;
  /** One line on why it matters, under the question. */
  context?: string;
  /** Data form. If omitted, the component reads `<Option>` children. */
  options?: readonly DecisionOption[];
  /** The recommendation, under the options. */
  recommendation?: React.ReactNode;
  /** `<Option>` items. */
  children?: React.ReactNode;
  /** Additional classes for the frame. */
  className?: string;
}

/** A decision laid out as options with costs, with the recommended one marked. */
export const Decision = React.forwardRef<HTMLDivElement, DecisionProps>(function Decision(
  { question, context, options: optionsProp, recommendation, children, className, ...rest },
  ref,
) {
  const options = optionsProp ?? childItems(children, Option);
  return (
    <div ref={ref} role="group" aria-label={question} {...rest} className={cn('border-[3px] border-intent-warning bg-surface-raised shadow-hard-md', className)}>
      <div className="border-b-2 border-intent-warning px-4 py-3">
        <p className="m-0 font-display text-base font-extrabold text-content-primary">{question}</p>
        {context && <p className="m-0 mt-1 font-mono text-xs text-content-muted">{context}</p>}
      </div>
      <div className="grid sm:grid-cols-2">
        {options.map((o) => (
          <div key={o.title} data-slot="decision-option" className={cn('flex flex-col gap-2 border-b border-edge-subtle px-4 py-3 sm:odd:border-r', o.picked && 'bg-surface-sunken')}>
            <p className="m-0 flex items-baseline justify-between gap-2 font-display text-sm font-bold text-content-primary">
              <span>{o.title}</span>
```

```tsx
export interface TermItem {
  /** The word being defined. */
  term: string;

  children?: React.ReactNode;

/** MDX-only glossary entry, for example `<Term term="Chroma" scale="0 = grey">How colourful.</Term>`. */
export const Term = defineAsciiItem<TermItem>('Term');

export interface TermGridProps extends React.HTMLAttributes<HTMLDListElement> {
  /** Accessible name for the glossary. */
  label?: string;
  /** Data form. If omitted, the component reads `<Term>` children. */
  terms?: readonly TermItem[];
  /** `<Term>` items. */
  children?: React.ReactNode;
  /** Additional classes for the grid. */
  className?: string;
}

/** A glossary of the words a page depends on, each with a plain-language scale. */
export const TermGrid = React.forwardRef<HTMLDListElement, TermGridProps>(function TermGrid(
  { label = 'Terms', terms: termsProp, children, className, ...rest },
  ref,
) {

          {t.scale && <dd className="m-0 font-mono text-xs text-content-muted">{t.scale}</dd>}
```
