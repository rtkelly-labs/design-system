# mdxcn attribution

This package adapts selected components from [mdxcn](https://github.com/keshav-exe/mdxcn),
which is copyright Keshav Bagaade and licensed under the MIT License.

The source was reviewed at commit
[`2928126ba146ebbae9c2351deca27d27bb40e744`](https://github.com/keshav-exe/mdxcn/tree/2928126ba146ebbae9c2351deca27d27bb40e744).
Each adapted component also carries a source link in its file header.

Copied/adapted upstream paths:

- `registry/default/graph-frame/graph-frame.tsx`
- `registry/default/graph-flow/graph-flow.tsx`
- `registry/default/graph-timeline/graph-timeline.tsx`
- `registry/default/graph-diff/graph-diff.tsx`
- `registry/default/graph-slope/graph-slope.tsx`
- `registry/default/graph-uptime/graph-uptime.tsx`
- `registry/default/graph-tree/graph-tree.tsx`
- `registry/default/graph-activity/graph-activity.tsx`
- `registry/default/graph-gantt/graph-gantt.tsx`
- `registry/default/terminal/terminal.tsx`
- `registry/default/steps/steps.tsx`

The implementation in this package is adapted to the local semantic token, accessibility,
deterministic-rendering, and Storybook contracts. It does not add an `mdxcn` npm dependency.
